# 生活财务计算器 · 算法清单(微信小程序开发用)

> 说明:本清单参考"松鼠管家"类产品的5大分类结构(购房房贷/工资个税/购车用车/储蓄理财/生活日常),
> 因无法抓取到对方网站每个子分类页面的精确工具命名,前五类是按行业通用做法重新规划、独立实现的
> 52个计算器。第六至十类是在此基础上做的差异化扩展(拼假、进阶个税社保、保险测算、房产进阶、
> 小众生活场景),用于覆盖对方尚未做全或完全空白的品类。公式均为国家公开法规/行业通用算法,
> 不涉及抄袭。可直接交给写代码的 AI 按此规格实现。
>
> **建议优先级**:拼假计算器(季节性流量入口)> 保险测算类(竞品空白)> 副业综合税负对比
> (需求上升明显)> 其余按开发资源排期。

## 一、购房房贷(8个)

### 1. 房贷计算器(商贷/公积金/组合贷)
- **输入**:贷款金额(商贷本金、公积金本金)、年利率(商贷利率、公积金利率,当前公积金利率一般 2.85%~3.1%,商贷参考 LPR 加点)、贷款年限、还款方式
- **等额本息月供**:
  ```
  月利率 r = 年利率 / 12
  月供 = P × r × (1+r)^n / ((1+r)^n - 1)
  P = 贷款本金,n = 还款总月数
  ```
- **等额本金第k月月供**:
  ```
  每月还本金 = P / n
  第k月月供 = P/n + (P - P/n×(k-1)) × r
  ```
- **组合贷**:商贷、公积金贷分别按各自本金和利率计算,月供为两者之和;总还款计划表按月合并展示
- **输出**:月供、总利息、总还款额、每月还款明细表

### 2. 提前还款计算器
- **输入**:原贷款信息、已还期数、提前还款金额、提前还款方式(缩短年限 / 减少月供)
- **算法**:
  - 剩余本金 = 按原还款方式计算到提前还款时点的剩余本金
  - 缩短年限:月供不变,重新计算还款期数 n' = ln(月供/(月供 - 剩余本金×r)) / ln(1+r)
  - 减少月供:期数不变,按新本金重新代入等额本息公式算新月供
- **输出**:节省利息、新还款计划、新月供或新年限

### 3. 公积金贷款额度计算器
- **输入**:月缴存基数、缴存比例、账户余额、房屋评估价、当地最高贷款限额、剩余工作年限
- **算法(简化通用规则)**:
  ```
  可贷额度 = min(
    月缴存额 × 倍数系数(各地一般40~50倍) × 12,
    账户余额 × N倍(各地不同,常见10~20倍),
    房屋评估价 × 成数(首套一般70%~80%),
    当地最高限额
  )
  ```
- **说明**:各地公积金政策差异大,建议做成"系数可调"的通用模型,前端标注"以当地公积金中心最新政策为准"

### 4. 购房能力计算器
- **输入**:家庭月收入、首付比例、贷款利率、贷款年限、月供收入占比上限(建议默认50%)
- **算法**:
  ```
  最大可承受月供 = 家庭月收入 × 月供占比上限
  反推最大贷款额 P(用等额本息公式反解):
  P = 月供 × ((1+r)^n - 1) / (r × (1+r)^n)
  可购房总价 = 最大贷款额 / (1 - 首付比例)
  ```
- **输出**:建议购房总价区间、压力测试(利率+1%/+2%情形下月供变化)

### 5. 租房vs买房对比计算器
- **输入**:房价、首付比例、贷款利率/年限、当前月租金、租金年涨幅、房价年增值率、理财年化收益率、对比年限
- **算法**:
  ```
  买房净成本(N年) = 首付 + N年月供总和 + 各类税费 - N年后房屋估值增值
  租房净成本(N年) = N年租金总和(逐年按涨幅递增) - 首付资金若用于理财的N年复利收益
  ```
- **输出**:N年后两种方案的净成本对比、盈亏平衡年限

### 6. 首付款计算器
- **输入**:房屋总价、首付比例(首套/二套/是否公积金)
- **算法**:`首付金额 = 总价 × 首付比例`,`贷款金额 = 总价 - 首付金额`
- **输出**:首付金额、贷款金额、契税等一次性费用预估

### 7. 契税计算器
- **输入**:房屋总价、面积、是否首套、是否唯一住房、城市
- **算法(现行通用规则,以官方最新政策为准)**:
  ```
  首套且≤140㎡(或90㎡新老口径视地方):1% (部分城市90-140㎡为1.5%)
  首套>140㎡ 或 二套:2%~3%(各地不同)
  契税 = 总价 × 适用税率
  ```
- **说明**:建议做成可配置税率表,并标注"以当地最新政策为准"

### 8. 二手房交易税费计算器
- **输入**:成交价、房屋原值、持有年限、是否满二/满五唯一、面积
- **算法**:
  ```
  增值税:满2年普通住宅免征,不满2年按差额或全额5.3%左右计征
  个人所得税:满五唯一免征;不满足条件时 = (成交价-原值-合理费用) × 20% 或 成交价×1%(核定征收,选低者,各地不同)
  契税:同上
  中介费:成交价 × 约1%~3%(可配置)
  ```
- **输出**:各项税费明细、总费用

## 二、工资个税(8个)

### 1. 个人所得税计算器(月度预扣预缴)
- **算法(累计预扣法,国家税务总局规定)**:
  ```
  累计应纳税所得额 = 累计收入 - 累计基本减除费用(5000×月数) - 累计专项扣除(五险一金) - 累计专项附加扣除 - 累计依法确定的其他扣除
  累计应纳税额 = 累计应纳税所得额 × 适用税率 - 速算扣除数
  本月应预扣税额 = 累计应纳税额 - 累计已预缴税额
  ```
- **七级超额累进税率表(年度,单位:元)**:
  ```
  ≤36000: 3%, 速算扣除数0
  36000-144000: 10%, 速算扣除数2520
  144000-300000: 20%, 速算扣除数16920
  300000-420000: 25%, 速算扣除数31920
  420000-660000: 30%, 速算扣除数52920
  660000-960000: 35%, 速算扣除数85920
  >960000: 45%, 速算扣除数181920
  ```

### 2. 年度汇算清缴计算器(退补税)
- **输入**:全年综合所得、全年已预缴税额、全年扣除项
- **算法**:`年度应纳税额 = (全年应纳税所得额) × 税率 - 速算扣除数`;`退/补税 = 已预缴 - 应纳税额`

### 3. 税后工资计算器(五险一金+个税)
- **算法**:
  ```
  五险一金个人部分 = 缴费基数 × (养老8% + 医疗2%+3 + 失业0.5% + 公积金比例,各地略有不同)
  应纳税所得额 = 工资 - 五险一金个人部分 - 5000 - 专项附加扣除
  个税 = 按上表累进计算(月度简化可用月度速算表)
  税后工资 = 工资 - 五险一金个人部分 - 个税
  ```
- **反算功能**:已知税后工资倒推税前工资(二分法或方程迭代)

### 4. 年终奖个税计算器(单独/合并对比)
- **单独计税**:
  ```
  月度平均值 = 年终奖 / 12,按月度税率表找税率和速算扣除数
  应纳税额 = 年终奖 × 税率 - 速算扣除数
  ```
- **合并计税**:并入全年综合所得按上表计算
- **临界点提醒**:在36000/144000/300000/420000/660000/960000附近,年终奖略微超过临界点可能导致税后所得反而减少,需在UI做提示并给出"最优发放金额"建议

### 5. 五险一金计算器
- **输入**:城市、缴费基数、单位/个人比例
- **算法**:`个人月缴 = 缴费基数 × 个人比例之和`,`单位月缴 = 缴费基数 × 单位比例之和`(各地比例需做成城市配置表)

### 6. 专项附加扣除计算器
- **输入**:子女教育、继续教育、大病医疗、住房贷款利息/住房租金、赡养老人、3岁以下婴幼儿照护等
- **算法**:按国家规定定额相加(如子女教育每孩每月2000元,赡养老人独生子女每月3000元等,定期核对官方标准)

### 7. 加班费计算器
- **算法**:
  ```
  工作日加班:月工资/21.75/8 × 1.5 × 加班小时数
  休息日加班(不补休):同基数 × 2倍
  法定节假日加班:同基数 × 3倍
  ```

### 8. 离职经济补偿金及个税计算器
- **经济补偿金(N)**:`补偿金 = 月平均工资(前12个月) × 工作年限(不满6个月按0.5年,满6个月不满1年按1年)`
- **个税**:当年一次性补偿收入在当地上年职工平均工资3倍以内免税,超出部分按月度税率表单独计税

## 三、购车用车(6个)

### 1. 车贷计算器
- 与房贷等额本息/等额本金公式一致,替换为车贷利率(一般高于房贷)、常见年限1-5年

### 2. 车辆购置税计算器
- **算法**:
  ```
  不含税价格 = 车辆价格 / (1 + 增值税率)   # 目前增值税率13%
  购置税 = 不含税价格 × 10%   # 新能源车视政策阶段性减半或免征
  ```

### 3. 二手车估值/残值计算器
- **算法(简化车龄折旧模型)**:
  ```
  残值率 = max(1 - 首年折旧率(约15%) - 后续每年折旧率(约8%~10%)×(车龄-1), 下限如20%)
  估值 = 新车指导价 × 残值率 × 里程系数 × 车况系数
  ```

### 4. 落地价计算器
- **算法**:`落地价 = 裸车价 + 购置税 + 车船税 + 保险费(交强险+商业险预估) + 上牌费等`

### 5. 车船税计算器
- **算法**:按排量分档定额征收(各省有幅度,需做省份配置表),例如:
  ```
  1.0L以下:60-360元/年
  1.0-1.6L:300-540元/年
  1.6-2.0L:360-660元/年
  ...(依据当地最新税额表配置)
  ```

### 6. 用车成本计算器(油耗/电耗)
- **算法**:
  ```
  百公里成本 = 百公里油耗(或电耗) × 油价(或电价) / 100 × 里程
  年度用车成本 = 燃油/电费 + 保险 + 保养 + 停车/过路费估算
  ```

## 四、储蓄理财(7个)

### 1. 存款利息计算器(单利)
- `到期利息 = 本金 × 年利率 × 存期(年)`

### 2. 定期存款复利计算器
- `到期本息 = 本金 × (1 + 年利率/计息周期数)^(计息周期数×年数)`

### 3. 基金定投计算器
- **算法(期末值,等额定投)**:
  ```
  FV = 每期投入 × [((1+r)^n - 1) / r]
  (期初投入模式再乘以 (1+r))
  r = 每期收益率,n = 投资期数
  ```
- 支持不定期追加、支持年化收益率敏感性分析

### 4. 复利计算器(通用)
- `A = P × (1 + r/n)^(n×t)`,P本金,r年利率,n年复利次数,t年数
- 支持定期追加本金的复利累积表

### 5. 通货膨胀计算器
- **算法**:
  ```
  未来所需金额 = 现在金额 × (1 + 通胀率)^年数
  货币实际购买力 = 当前金额 / (1 + 通胀率)^年数
  ```

### 6. 理财收益率换算计算器
- **算法**:年化收益率、七日年化、到期收益率之间互相换算;`实际收益 = 本金 × 年化收益率 × 天数/365`

### 7. 提前退休/FIRE(财务自由)计算器
- **算法**:
  ```
  所需资产 = 预计年支出 / 安全提取率(常用4%规则)
  达成年限:通过当前储蓄+年化收益率+每年新增投入,迭代计算资产增长到目标值所需年数
  ```

## 五、生活日常(23个)

1. **装修预算计算器**:按面积×每平米单价(可分档:简装/中装/精装)+人工/材料比例拆分,输出瓷砖/地板/涂料/壁纸/橱柜等分项预算
2. **瓷砖用量计算器**:`所需片数 = 铺贴面积 / 单片瓷砖面积 × (1+损耗率,一般5%~10%)`
3. **涂料用量计算器**:`所需涂料(L/kg) = 涂刷面积 × 遍数 / 每升(kg)理论覆盖面积`
4. **地板用量计算器**:与瓷砖类似,按地板规格折算片数/箱数
5. **壁纸用量计算器**:按房间周长、层高、壁纸幅宽计算所需卷数
6. **窗帘用量计算器**:按窗户宽度×倍率(一般2~2.5倍褶皱量)计算所需布料米数
7. **日期计算器**:计算两日期相差天数/月数/年数,支持工作日/节假日排除
8. **年龄计算器**:按出生日期精确计算周岁、虚岁、生肖
9. **退休年龄计算器**:按国家渐进式延迟退休新规,依出生年月+性别+原法定年龄计算具体退休日期
10. **工龄计算器**:累计计算多段工作经历的总工龄(用于经济补偿金、年假天数等场景)
11. **年假天数计算器**:按累计工龄对应国家规定天数(不满1年0天,1-10年5天,10-20年10天,20年以上15天)
12. **社保缴费年限计算器**:累计养老/医疗缴费年限,提示是否满足退休领取最低年限(养老15年、医疗各地不同)
13. **养老金测算器(简化版)**:
    ```
    基础养老金 = (退休时上年度社平工资×(1+本人平均缴费指数)/2) × 缴费年限 × 1%
    个人账户养老金 = 个人账户累计储存额 / 计发月数(按退休年龄对应,如60岁139个月)
    月养老金 = 基础养老金 + 个人账户养老金
    ```
14. **生育津贴计算器**:`生育津贴 = 单位上年度月平均工资 / 30 × 产假天数`
15. **BMI计算器**:`BMI = 体重(kg) / 身高(m)^2`,并给出体重分类
16. **孕期/预产期计算器**:末次月经日期 + 280天 = 预产期;反推孕周
17. **恋爱/结婚纪念日计算器**:计算相恋天数、下一个整百天/周年倒计时
18. **彩礼/婚礼预算计算器**:按彩礼、婚宴、婚纱摄影、蜜月等分项累加预算
19. **电费计算器**:按阶梯电价计算(第一档、第二档、第三档用电量对应不同单价,各地标准配置)
20. **水费计算器**:同阶梯水价逻辑
21. **快递/物流费用估算计算器**:按重量、体积重(长×宽×高/6000)取大者,结合首重续重单价计算
22. **停车费计算器**:按小时/分段收费规则(首小时、超时每小时)累加计算
23. **满减/折扣优惠计算器**:输入原价、折扣或满减规则,计算实付金额及实际折扣率;支持多张券叠加计算最优组合

## 六、话题性/季节性工具(扩展分类)

### 1. 拼假计算器
- **输入**:年度法定节假日安排(需按官方每年公布的调休表配置)、可用年假天数、目标假期(如"十一"、"春节")
- **算法**:
  ```
  枚举请假区间组合(如目标节日前后±N个工作日),
  对每种组合计算:实际请假天数 = 组合中的工作日数量
                连续休息天数 = 组合总天数(含调休上班日需排除)
  按"连续休息天数 / 请假天数"性价比排序,推荐最优/次优方案
  ```
- **说明**:法定节假日+调休安排每年国务院公布一次,需做成"年度配置表",每年更新一次即可

### 2. 满减/优惠券最优组合计算器(进阶版,区别于第五类第23项的简单版)
- **输入**:购物车商品清单及金额、多个满减规则(如满300减50、满500减90)、可叠加的优惠券(无门槛券、折扣券)
- **算法**:
  ```
  本质是背包/组合优化问题:
  枚举商品在不同店铺/订单间的拆分方式 × 每种拆分下可用的满减档位,
  计算每种组合的实付金额,取最小值
  (商品数量较多时可用贪心+启发式,而非完全穷举,避免组合爆炸)
  ```

### 3. 压岁钱/份子钱记账与平衡计算器
- **输入**:历年收送记录(对象、金额、场合、方向:收/送)
- **算法**:
  ```
  按对象汇总:该对象净收支 = 收到金额之和 - 送出金额之和
  提示"人情往来是否失衡"及建议下次随礼参考金额(按对方历史随礼金额×当地行情系数)
  ```

## 七、个税/社保进阶与边缘场景

### 1. 经营所得个税计算器(个体工商户/灵活就业)
- **算法(五级超额累进,年度)**:
  ```
  应纳税所得额 = 收入总额 - 成本费用 - 损失 - 允许扣除项 - 减除费用(5000×12,可用于个体户经营者本人)
  ≤30000: 5%,速算扣除数0
  30000-90000: 10%,速算扣除数1500
  90000-300000: 20%,速算扣除数10500
  300000-500000: 30%,速算扣除数40500
  >500000: 35%,速算扣除数65500
  应纳税额 = 应纳税所得额 × 税率 - 速算扣除数
  ```

### 2. 灵活就业人员社保缴纳计算器
- **输入**:所在城市、选择的缴费基数档位(通常在当地社平工资60%~300%间可选)
- **算法**:
  ```
  养老保险:缴费基数 × 20%(全部个人承担,其中12%记入统筹、8%记入个人账户,比例各地可能略有差异)
  医疗保险:缴费基数 × 当地灵活就业医保比例(常见8%左右,各地不同)
  月缴总额 = 养老 + 医疗(+大病医疗补充,视当地政策)
  ```
- **说明**:需做城市配置表,与职工社保比例区分开

### 3. 劳务报酬个税计算器(稿酬/劳务费,按次代扣代缴)
- **算法**:
  ```
  每次收入≤4000元:应纳税所得额 = 收入 - 800
  每次收入>4000元:应纳税所得额 = 收入 × (1 - 20%)
  应纳税额 = 应纳税所得额 × 20%
  若应纳税所得额超过20000元,超出部分加成征收:
    20000-50000部分:税率30%(速算扣除数2000)
    超过50000部分:税率40%(速算扣除数7000)
  稿酬所得额外享受70%计税(即再乘以0.7)
  ```

### 4. 失业金领取计算器
- **输入**:累计缴纳失业保险年限、当地失业金标准
- **算法**:
  ```
  领取月数:缴费满1年不满5年→最长12个月;满5年不满10年→最长18个月;满10年以上→最长24个月
  (每多缴1年可累加,各地细则略有差异,需配置表)
  月领取金额 = 当地失业保险金标准(常与当地最低工资挂钩,如最低工资的80%~90%)
  ```

### 5. 工伤/医疗期工资计算器
- **算法**:
  ```
  停工留薪期:原工资福利待遇不变,由单位按月支付,一般不超过12个月(伤情严重可延长)
  医疗期长短:按本人实际工作年限和本单位工作年限确定(3个月到24个月不等,国家有对照表)
  医疗期内病假工资 = 本人工资 × 病假工资系数(通常60%~100%,各地/单位规定不同)
  ```

## 八、保险测算类(空白品类,建议重点做)

### 1. 重疾险保额测算器
- **算法(需求法,常见简化模型)**:
  ```
  建议保额 = 治疗康复费用预估(30万~50万) 
           + 康复期收入损失(年收入 × 2~3年)
           + 已有负债(房贷余额等,可选加成)
           - 已有重疾险保额及社保报销能力抵扣
  ```

### 2. 寿险保额计算器(收入损失法/需求法)
- **算法**:
  ```
  收入损失法:建议保额 = 年收入 × 家庭责任年限(通常至子女独立/房贷还清)
  需求法:建议保额 = 家庭负债总额(房贷/车贷等) + 子女教育金预留 + 父母赡养金预留 + 家庭年支出×缓冲年数 - 现有资产及保障
  ```

### 3. 社保 vs 商业医疗险报销对比计算器
- **输入**:医疗总费用、社保报销比例及封顶线、商业医疗险免赔额及报销比例
- **算法**:
  ```
  社保报销 = min(费用×社保报销比例, 社保封顶线) (需扣除社保目录外费用)
  商业险报销 = max(0, (费用 - 社保报销 - 免赔额)) × 商业险报销比例
  个人自付 = 总费用 - 社保报销 - 商业险报销
  ```

## 九、房产/资产进阶工具

### 1. 学区房溢价性价比计算器
- **输入**:学区房总价、同片区非学区房价、孩子距离入学剩余年限、预计持有年限
- **算法**:
  ```
  学区溢价 = 学区房总价 - 非学区房总价
  折算年成本 = 学区溢价 / 预计持有年限(或按机会成本用理财收益率折现)
  与校外择校费/私立学费/学区房转手溢价保留情况对比,给出"是否划算"参考
  ```

### 2. 房产投资回报率(租售比)计算器
- **算法**:
  ```
  租金回报率(年化) = 年租金收入 / 房屋总价 × 100%
  租售比 = 房屋总价 / (月租金 × 12)  (国际通行警戒线约1:200~1:300)
  扣除持有成本后净回报率 = (年租金 - 物业费 - 维修基金摊销 - 房贷利息) / 总投入
  ```

### 3. 房屋维修基金/物业费计算器
- **算法**:
  ```
  维修基金 = 建筑面积 × 当地每平米标准(各城市定额或按房价比例,常见1%~2%房款)
  物业费(年) = 建筑面积 × 每平米月单价 × 12
  ```

## 十、小众但差异化的生活工具

### 1. 异地恋/异地工作通勤成本计算器
- **算法**:
  ```
  单次往返成本 = 交通费(高铁/机票取低者) + 时间成本(往返耗时 × 个人时薪估算)
  年度总成本 = 单次成本 × 年度往返频次
  ```

### 2. 宠物养育成本计算器
- **算法**:
  ```
  年度成本 = 主粮/零食 + 医疗驱虫疫苗 + 洗澡美容 + 用品损耗 + 寄养/托管(按品种体型分档给默认值参考)
  终身成本 = 年度成本 × 预期寿命(按品种给参考值,如猫12-16年、中型犬10-13年)
  ```

### 3. 副业/自由职业者综合税负对比计算器(重点推荐,需求上升明显)
- **算法**:
  ```
  模式一(个体工商户核定征收):应纳税额 = 收入 × 核定应税所得率(各地不同,常见5%~10%) × 经营所得税率表
  模式二(个体工商户查账征收):按经营所得五级累进(见第七类第1项)
  模式三(灵活用工/劳务报酬代发):按劳务报酬个税规则(见第七类第3项)
  模式四(全职单位代发工资):按工资薪金个税规则
  对比四种模式在同等收入下的实际到手金额,给出最优选择建议
  ```

## 十一、AI原生扩展功能(基于"AI小程序成长计划"免费额度)

> 依赖资源:微信"AI应用及线上工具小程序成长计划"赠送的腾讯混元 **文生文(混元2.0,1亿token)**
> 和 **文生图(hunyuan-image-v3.0,1万张)** 额度,通过微信云开发 AI 模块调用。
> **重要说明**:该免费额度只覆盖"文字→文字"和"文字→图片"两种能力,**不包含"图片→文字"的
> 识图/OCR能力**(比如拍照识别工资条),这类需求要另接腾讯云付费视觉理解/OCR接口,不占用本额度,
> 建议作为后续独立预算规划,不要一开始就绑进这1亿token里。

### 1. 自然语言驱动的计算器入口(文生文)
- **能力**:文生文(意图识别 + 参数抽取)
- **输入**:用户一句自然语言描述,如"我月薪2万在北京,算下五险一金和到手工资"
- **处理逻辑**:
  ```
  Prompt设计:将52+个计算器的名称、所需参数字段列表作为system prompt的"工具清单",
  要求模型以固定JSON格式输出:{ "tool": "税后工资计算器", "params": {"城市":"北京","月薪":20000} }
  若参数不全,要求模型返回缺失字段列表,由前端追问用户补全
  ```
- **输出**:结构化JSON → 前端据此跳转对应计算器页面并预填参数
- **注意**:务必对模型输出做JSON解析容错(可能输出多余文字),建议加"仅输出JSON,不要任何解释"的约束

### 2. 综合财务健康度点评(文生文)
- **能力**:文生文
- **输入**:用户在小程序内多个计算器的历史计算结果(如房贷月供、税后工资、储蓄理财目标)
- **处理逻辑**:
  ```
  将结构化数据(月供收入比、储蓄率、负债情况等)拼成文本喂给模型,
  要求输出一段200字以内的点评+2-3条具体建议
  ```
- **合规注意**:
  - 输出内容必须包含免责声明,如"以上内容仅为信息参考,不构成投资或财务建议,具体决策请咨询专业顾问"
  - Prompt 中明确要求模型语气克制、不做保证性表述(避免"稳赚""一定能"这类措辞)
  - 不涉及具体投资产品推荐,只做"是否合理""建议方向"层面的定性点评

### 3. 政策问答小助手(文生文 + 检索增强,非模型自由发挥)
- **能力**:文生文,但**必须做成检索增强(RAG)模式**,而非直接问答
- **处理逻辑**:
  ```
  1. 自行整理契税、公积金、专项附加扣除、个税税率表等官方政策原文,存入云数据库作为知识库
  2. 用户提问 → 先在知识库中检索相关政策条目 → 将检索到的原文片段+用户问题一起喂给模型
  3. Prompt 要求模型"仅基于提供的政策原文回答,不要编造未提及的内容;
     若原文未覆盖用户问题,明确告知用户'该问题暂无法从现有政策库中确认,建议咨询当地相关部门'"
  ```
- **输出**:附带政策来源文件名+更新日期,增强可信度
- **注意**:这是全部AI功能里**风险最高**的一项,模型编造政策细节的后果比较严重(用户可能真的据此去交税/办贷款),知识库必须定期人工核对更新,不能长期不维护

### 4. 年度财务总结海报(文生图)
- **能力**:文生图(hunyuan-image-v3.0)
- **输入**:用户全年使用各计算器的关键数据(如全年个税、房贷已还金额、储蓄增长)
- **处理逻辑**:
  ```
  1. 先用文生文能力把数据整理成一段简洁的"年度总结文案"(如"这一年,你为房子多还了X万本金,
     个税优化省下Y元,储蓄增长Z%")
  2. 将文案作为 prompt 传给文生图接口,指定风格(如"简约商务风信息图,配色蓝白,包含数字大字体展示")
     hunyuan-image-v3.0 支持自定义宽高比,建议做成适合微信分享的竖版比例(如3:4)
  ```
- **输出**:一张可保存/分享到朋友圈的年度账单风格海报
- **增长价值**:自带分享裂变属性,建议在生成后引导"保存图片"或"分享给好友",作为获客入口

### 5.(备选,不占免费额度,需另行付费规划)工资条/票据智能解析
- **所需能力**:图片理解/OCR(不在免费文生文文生图额度内)
