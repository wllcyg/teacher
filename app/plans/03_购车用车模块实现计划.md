# 03 · 购车用车模块实现计划

## 一、模块目标与定位
为消费者购车与长期养车提供精准透明的资金账本，涵盖从选车落地总价预估、车贷实际利率识别，到持有期间燃油/纯电能耗与二手车折旧测算。

---

## 二、包含计算器清单与算法实现规范 (共 6 个)

### 1. 车贷计算器 (含真实年化利率 IRR)
- **输入**：裸车价、首付比例、分期月数 (12~60期)、名义费率或月供、金融服务费（4S店常见 3000-8000 元）。
- **算法模型**：
  - **等额本息/等额本金还款计划**：与房贷相同公式。
  - **真实综合年化利率 (IRR) 反解算法**（揭露"零利率实际高息"陷阱）：
    $$\sum_{t=0}^{n} \frac{CF_t}{(1 + IRR_{month})^t} = 0$$
    其中：
    - $CF_0 = P_{net}$（期初实际到手本金 = 裸车价 $\times$ (1 - 首付比) - 金融服务费 - 上牌等杂费）
    - $CF_{1 \sim n} = -M$（每月月供为负现金流）
    - 通过 **Newton-Raphson 数值迭代**求解月利率 $IRR_{month}$，年化 IRR = $IRR_{month} \times 12$
  - **案例对比展示**：
    - 名义年利率 0%，但收取金融服务费 6000 元 $\to$ 真实 IRR = 7.2%
    - 名义年利率 3.5%，无服务费 $\to$ 真实 IRR = 3.5%
    - 直观告警："所谓 0 息贷款实际比银行车贷还贵 3.7%"

### 2. 车辆购置税计算器
- **算法**：
  $$\text{不含税价} = \frac{\text{发票价格}}{1 + 13\%} \implies \text{购置税} = \text{不含税价} \times 10\%$$
- **新能源优惠政策模型**：根据国家新能源汽车免征/限额减半政策动态配置扣减。

### 3. 二手车估值 / 残值计算器
- **算法模型**：
  $$\text{残值率} = \max(1 - \text{首年折旧(约15\%)} - \text{年折旧率(8\%~10\%)} \times (\text{车龄}-1), 20\%)$$
  $$\text{预估残值} = \text{新车指导价} \times \text{残值率} \times \text{里程修正系数} \times \text{车况等级系数}$$

### 4. 落地总价计算器
- **费用项拆解**：
  $$\text{落地价} = \text{裸车成交价} + \text{车辆购置税} + \text{车船税} + \text{交强险} + \text{商业险预估} + \text{上牌杂费}$$

### 5. 车船税计算器
- **阶梯排量税额配置表**：1.0L以下 (60-360元)、1.0-1.6L (300-540元)、1.6-2.0L (360-660元)、2.0-2.5L (660-1200元) 等，支持省份差异动态调整。

### 6. 用车养车年度成本计算器 (油车 vs 电车)
- **能耗成本**：
  - 燃油车：$\text{百公里油耗} \times \text{实时油价} / 100 \times \text{年行驶里程}$
  - 纯电动：$\text{百公里电耗} \times \text{电价(家充/公桩加权)} / 100 \times \text{年行驶里程}$
- **综合养车成本**：能耗 + 每年保险 + 每年常规保养 + 停车与高速过路费汇总。
