# 11 · AI 原生扩展功能实现计划

## 一、模块目标与定位
依托微信“AI应用成长计划”赋能的腾讯混元大模型免费资源：
- **混元文生文 (hunyuan-standard, 1亿 Token)**
- **混元文生图 (hunyuan-image-v3.0, 1万张)**
将传统“被动输入表单”的计算器，升级为“主动理解用户意图、权威政策知识库问答、以及个性化视觉海报生成”的智能财务顾问。

---

## 二、四大 AI 能力详细实现方案

### 1. 自然语言驱动的计算器入口 (文生文：意图识别 + 参数抽取)
- **业务场景**：用户不清楚该用 67 个计算器中的哪一个，直接在首页搜索框或 AI 助手输入自然语言（例如：“*我在深圳月薪2万4，算下每个月到手多少钱和公积金扣多少*”）。
- **云开发 AI 调用与 Prompt 设计**：
  ```json
  // System Prompt: 将计算器列表作为 Function/Tool 字典注入
  {
    "role": "system",
    "content": "你是一个财务计算器分流专家。根据用户输入，识别目标计算器与提取参数。必须仅输出如下格式的严格JSON，严禁任何额外解释：\n{ \"tool\": \"salary\", \"params\": {\"city\": \"深圳\", \"gross_salary\": 24000} }"
  }
  ```
- **前端闭环逻辑**：
  1. 调用云函数 `cloudfunctions/ai-intent/`。
  2. 对模型返回做鲁棒的 JSON 提取与容错清洗。
  3. 前端自动携带 `params` 跳转到对应计算器页面：`wx.navigateTo({ url: '/pages/result/result?type=salary&preload=' + encodeURIComponent(JSON.stringify(params)) })`。
  4. 计算器页面自动将参数填入输入框并完成计算，用户体验极其惊艳！

### 2. 综合财务健康度智能点评 (文生文)
- **业务场景**：用户在计算房贷、薪资、年终奖后，系统将结构化财务指标（如月供收入比 48%、年储蓄率 15%、综合税负 8%）聚合。
- **大模型处理**：
  - 输出 150~200 字极简专业的定性健康度点评，并给 2~3 条客观优化建议。
  - **合规保障**：强制输出标准免责声明：“*以上分析仅供个人财务规划参考，不构成任何投资咨询或承诺*”。

### 3. 政策问答小助手 (RAG 检索增强架构，严禁模型胡编)
- **风险控制 (PRD 重点预警)**：财税房产政策容错率极低，大模型幻觉可能误导用户。
- **技术落地流程**：
  1. **知识库构建**：将国家税务总局专项附加扣除官方问答、央行最新 LPR 基准、契税新政全文切片存入云数据库集合 `policy_knowledge`。
  2. **检索增强**：用户提问 $\to$ 云函数在知识库中向量/关键词检索最相关的 3 条政策原文片段。
  3. **受限问答**：将政策片段拼入 Prompt：“*仅根据提供的以下政策原文回答用户问题。若原文未提及，明确回复‘该问题暂无法从权威政策库中确认，请咨询当地税务或不动产部门’*”。
  4. **回答附注来源**：回答末尾标明出处（如《国家税务总局公告2023年第X号》），极度专业可信。

### 4. 年度财务总结海报 (混元文生图 hunyuan-image-v3.0)
- **业务场景**：结合用户在小程序内的年度计算痕迹或自定义填写的年度总结数据，生成微信朋友圈裂变海报。
- **两阶段生成工作流**：
  - **阶段一 (文案提炼)**：文生文提炼出富有仪式感的 4 句总结文案（如：“这一年，你为家庭资产稳健筑基，年化利息优化节省 8,400 元…”）。
  - **阶段二 (生图或 Canvas 混合排版)**：
    - 调用 `hunyuan-image-v3.0` 生成艺术质感的主题插画背景。
    - 前端小程序 Canvas / Snapshot 动态将用户数据、标签与二维码绘制合成，支持一键保存高清图片到相册。
