# 04 · 储蓄理财模块实施细则与开发任务书

## 一、 算法核心与公式设计 (`miniprogram/utils/calculators/finance.js`)

统一使用 `miniprogram/utils/math.js` 中的高精度浮点工具（基于 Big.js），彻底消除金融分厘误差与 IEEE 754 精度缺陷。

### 1. 存款利息计算器 (单利模型) `calcDepositInterest`
- **公式**：$I = P \times r \times t$
  - 按年计息：$t = \text{years}$
  - 按月计息：$t = \text{months} / 12$
  - 按日计息：$t = \text{days} / 365$
- **特性**：内置六大国有行最新活期、定期各档期（3个月、半年、1年、2年、3年、5年）及大额存单基准利率一键填充。
- **输出**：本息合计、纯利息、到期收益率、日均收益。

### 2. 定期存款复利计算器 `calcCompoundDeposit`
- **公式**：$A = P \times \left(1 + \frac{r}{m}\right)^{m \times t}$
  - $m$ 为年计息复利次数（按日 365、按月 12、按季 4、按半年 2、按年 1）
- **输出**：复利到期本息、纯复利利息、相比单利额外多赚利息（复利增益）、实际有效年利率 (APY/EAR)。

### 3. 基金定投计算器 (等额定投复利终值) `calcFundAIP`
- **公式 (期末定投)**：
  $$FV = P \times \left[ \frac{(1+r)^n - 1}{r} \right]$$
  - 按月定投：$r = R / 12, n = N \times 12$
  - 按周定投：$r = R / 52, n = N \times 52$
- **公式 (期初定投)**：$FV_{begin} = FV \times (1+r)$
- **敏感性阶梯分析**：输出当收益率浮动 $-4\%, -2\%, \pm 0\%, +2\%, +4\%$ 时的终值对比矩阵。
- **输出**：累计定投本金、最终总资产、定投资产收益、总收益率、收益率敏感性分析表。

### 4. 通用复利计算器 (含定期追加本金) `calcUniversalCompound`
- **支持**：初始本金 + 每月/每年定期追加储蓄 + 复利频次。
- **逐年推演轨迹**：计算输出每一年年初本金、本年追加、本年利息、年末总资产及利息与本金占比（可用于可视化进度条与明细账单）。
- **输出**：终值总资产、总本金、总利息、利息占比、逐年递增明细列表 `schedule`。

### 5. 通货膨胀与实际购买力计算器 `calcInflation`
- **公式**：
  $$\text{未来等值所需金额} = M \times (1 + i)^t$$
  $$\text{现在资金在未来实际购买力} = \frac{M}{(1 + i)^t}$$
  $$\text{累计购买力缩水率} = \frac{M - PV_{real}}{M} \times 100\%$$
- **输出**：未来等值金额、实际购买力、累计贬值率、逐年购买力衰减明细阶梯。

### 6. 理财收益率换算计算器 `calcYieldConvert`
- 覆盖常见 4 种互相换算：
  1. 日万份收益 $\leftrightarrow$ 年化收益率（$\text{年化} = \text{日万份} \times 365 / 10000$）
  2. 7日年化收益率 $\leftrightarrow$ 日收益与指定期限利息
  3. 封闭期到期收益率 $\leftrightarrow$ 年化综合收益率（$\text{年化} = \text{到期收益率} \times 365 / \text{天数}$）
  4. 实际收益核算（本金 × 年化 × 天数 / 365）

### 7. FIRE 提前退休 / 财务自由计算器 `calcFIRE`
- **核心标准**：
  - 经典 FIRE（4% 安全提取率）：目标资产 = 年支出 × 25
  - 瘦 FIRE（5% 提取率，极简生活）：目标资产 = 年支出 × 20
  - 肥 FIRE（3% 提取率，高品质晚年）：目标资产 = 年支出 × 33.3
  - 海岸 FIRE (Coast FIRE)：现有资产完全不追加，仅凭年化复利在目标年龄自动滚至经典 FIRE 所需本金
- **达成年限迭代算法**：
  - 年化真实回报率考虑：$r = \frac{1 + \text{投资名义回报率}}{1 + \text{通胀率}} - 1$
  - 从当前年龄逐年递推资产：$A_{k+1} = A_k \times (1 + r) + \text{每年新增储蓄}$
  - 精确推导出达成退休目标年限、达成时的目标年龄、资产积累曲线以及 FIRE 后的每月安全被动现金流。

## 二、 政策与基准配置中心 (`miniprogram/utils/config/finance-rates.js`)

- 六大国有银行存款挂牌基准利率；
- 大额存单市场参考利率；
- 历年温和/稳健通胀率预设档位（2.0%, 2.5%, 3.0%, 4.0%）；
- FIRE 预设生活档位（极简 4000/月、舒适 8000/月、品质 15000/月、轻奢 25000/月）。

## 三、 展示层与交互设计 (`pages/result/result` & 首页联动)

### 1. `pages/result/result` 增加储蓄理财模式 (`type === 'saving'`)
- 顶部子模块 Segmented Tab 切换：
  - **复利与定投** (`compound`)
  - **FIRE 财务自由** (`fire`)
  - **通胀与购买力** (`inflation`)
  - **收益率换算** (`yield`)
- **UI 风格遵循 `wechat-miniprogram-ui-design` 规范**：
  - 采用优雅的高端紫/蓝科技金融配色体系（紫色 Gradient Accent：`#7C3AED` ~ `#6D28D9`）；
  - 数据焦点高亮看板：总资产终值、复利收益、FIRE 达成年龄等核心指标；
  - 触摸按压反馈与触觉震动 (`wx.vibrateShort({ type: 'light' })`)；
  - 逐年资产增长轨迹弹窗（包含本金与利息双重柱状占比条）。

### 2. 首页与专题页联动
