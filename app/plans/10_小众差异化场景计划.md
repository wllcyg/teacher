# 10 · 小众但差异化生活工具实现计划

## 一、模块目标与定位
PRD 重点突出 **“副业/自由职业者综合税负对比计算器 (重点推荐，需求上升明显)”**。在灵活用工与副业经济爆发的当下，针对年轻一代职场人和自由职业者，直击“哪种纳税方式到手最多”的核心痛点，并提供新奇趣味的宠物与通勤生活算法。

---

## 二、包含计算器清单与算法实现规范 (共 3 个)

### 1. 副业 / 自由职业者综合税负对比计算器 (PRD 核心推荐)
- **业务痛点**：做自媒体、独立咨询、接外包或做电商，客户要求开票或走代发，不知道注册个体户、走灵活用工平台、签兼职劳务还是挂靠发票哪个最划算。
- **输入参数**：全年副业/经营收入规模 (如 10万、30万、100万)、可取得的合规成本发票额度、所在城市。
- **4 种模式横向并行算法**：
  1. **模式一：个体工商户 (核定征收模式)**：
     - 应纳税所得额 = 收入 $\times$ 核定应税所得率 (各地不同，常见 5%~10%)。
     - 按经营所得税率表计税，加上增值税 (小规模 1%) 与附加税。
  2. **模式二：个体工商户 (查账征收模式)**：
     - 应纳税所得额 = 收入 - 实际合规成本费用 - 60,000 元减除项。
     - 适用 5%~35% 五级超额累进经营所得税率。
  3. **模式三：灵活用工 / 劳务报酬 (按次代扣代缴)**：
     - 适用劳务报酬 20%~40% 加成征收税率，年底并入综合所得汇算。
  4. **模式四：全职兼任 (合并入工资薪金综合所得)**：
     - 与主业工资累加，适用 3%~45% 超额累进税率（通常落入 20%~35% 高税率区间）。
- **输出决策大盘**：
  - **4 种模式在同一收入下的实际到手金额横向对比柱状图**。
  - 净税负率（综合税费 / 总收入）。
  - 明确结论：“在当前 XX 万年收入下，推荐采用【个体工商户核定征收/查账征收】，比劳务报酬多到手 XX,XXX 元”。

### 2. 异地恋 / 异地双城通勤综合成本计算器
- **算法模型**：
  $$\text{单次往返显性支出} = \text{高铁/机票票价} + \text{往返打车/地铁} + \text{周末住宿餐饮差价}$$
  $$\text{单次隐性时间成本} = \text{单次往返总耗时(小时)} \times \text{个人时薪换算}$$
  $$\text{年度总成本} = (\text{显性支出} + \text{时间成本}) \times \text{年度往返频次}$$

### 3. 宠物全生命周期养育成本计算器
- **算法模型**：
  - 品种体型配置：猫咪（英短/美短/布偶等）、小型犬、中大型犬。
  - 年度刚性支出：主粮 + 零食罐头 + 疫苗驱虫体检 + 洗澡美容 + 玩具耗材 + 寄养托运。
  - 医疗与老年储备金：按品种常见遗传病预留应急备用金。
  - **全生命周期终身成本** = 年度支出 $\times$ 预期寿命 (猫 14-18 年，小型犬 12-16 年，大型犬 10-12 年) + 医疗准备金。
