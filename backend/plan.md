# 🗺️ 超级早报引擎：多频道架构演进计划 (多主题共存)

**核心目标**：将现有的“单机版”极客早报引擎，重构为支持**“多租户 / 多主题共存”的超级 Channel (频道) 架构**。让代码逻辑彻底与业务解耦，实现“AI 极客早报”与“初中地理教研内参”在同一台服务器上每天并列运行、互不干扰。

---

## 📅 Phase 1: 突破信息孤岛，搜集全领域“数据源”
地理教研频道无法像科技频道那样直接获取 RSS，我们需要建立专门针对微信生态的“破壁机”。

1. **部署微信公众号 RSS 转换器 (WeWe-RSS)**
   - 在您的 1C1G 云服务器上部署轻量级的 [WeWe-RSS](https://github.com/cooderl/wewe-rss)。
   - 使用闲置微信小号（**防风控封禁大号**）扫码登录，定向订阅《中学地理教学参考》等顶尖名师工作室公众号，获取 `.xml` 订阅链接。
2. **接入教育开源社区 (RSSHub)**
   - 使用 RSSHub 获取学科网等封闭题库站的最新中考套卷发布动态。

---

## 📅 Phase 2: 配置文件频道化重构 (`config.yaml`)
将全局配置改为数组形式的 `channels`，为每个频道注入独立的灵魂和数据源。

```yaml
# config.yaml (未来重构的终极形态)
channels:
  # ---------------- 频道 1：科技极客版 (已完成) ----------------
  - id: "tech_newsletter"
    title: "AI 极客早报"
    recipient_email: "904039807@qq.com"
    rss_urls:
      - url: "https://openai.com/news/rss"
        source_type: "rss"
    prompts:
      scorer_prompt: "关注AI前沿突破与硬核代码，过滤水文..."
      writer_prompt: "你是一位资深AI开发者，请为极客圈总结今天的新闻..."

  # ---------------- 频道 2：初中地理版 (新增) ----------------
  - id: "geo_teaching"
    title: "初中地理·教研内参"
    recipient_email: "geo_teacher@163.com"
    rss_urls:
      - url: "http://您的服务器IP:端口/wewe-rss/中学地理教学参考.xml"
        source_type: "rss"
    prompts:
      scorer_prompt: "关注中考地理命题方向、创新课堂教学设计..."
      writer_prompt: "你是一位拥有 20 年教龄的初中地理特级教师。请为一线老师提炼能够直接用在明天课堂上的 3 个中考考点与备课建议..."
```

---

## 📅 Phase 3: 流水线核心代码解耦 (Prompt 剥离)
剥离硬编码，赋予大模型“精神分裂式”的多重身份。

1. **改造 Agent (打分特工与撰稿特工)**
   - 修改 `agent_scorer.py` 和 `agent_writer.py`，将原本写死在 Python 里的 Prompt 移除，改为从 `channel["prompts"]` 中动态读取。
2. **改造 Workflow 循环分发**
   - 在 `workflow.py` 最外层增加 `for channel in config["channels"]` 遍历逻辑。
   - 系统将自动为极客频道提取 AI 干货，接着为地理频道提炼中考考点，最后分别推送到对应老师的专属邮箱中。

---

## 📅 Phase 4: 前端排版与独立主题适配
为了让教师和程序员都能获得最佳的阅读体验，渲染器也需要支持多频道自适应。

1. **主题感知**：修改 `wechat_formatter.py`，如果传入的是科技频道，继续使用“极客蓝”配色和极简封面；如果是地理频道，则切换至“自然绿”与“学术风”排版。
2. **联调测试**：启动系统，验证同一个引擎是否能在一分钟内，向两个不同的邮箱分别投递出两种完全不同文风和排版的高质量内参。

### 💡 终极愿景
完成这套“频道化”改造后，您不仅兼顾了极客与地理老师的需求。未来只需向 YAML 文件中增加几十行配置，您的系统就能立刻扩展出“金融交易内参”、“高中历史简报”等无限多个垂直领域的早报引擎！
